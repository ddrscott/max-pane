# Paste history: what you pasted and copied lately, in a picker

## Problem

iTerm's ⇧⌘H recalls recent pastes. The owner copies a path, copies something
else, and wants the path back. Max Pane already keeps unlimited visit history
with a fast ranked picker; this is the same idea for the clipboard, with more
care because clipboards hold secrets.

## Acceptance Criteria

- **What is recorded:** text pasted into a terminal with any paste command,
  and text copied *from* a terminal (⌘C, copy-on-select if on, OSC 52 writes if
  that task has landed). **Not** the system clipboard at large: Max Pane does
  not poll `NSPasteboard`. That is the line that keeps this from being a
  keylogger; write it in the ADR.
- **Never recorded:** anything when the pasteboard carries
  `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType` or
  `org.nspasteboard.AutoGeneratedType` (what 1Password and friends set);
  anything pasted into or copied from a **private lane**; anything over
  64 KB; and entries matching obvious secret shapes (`sk-…`, `ghp_…`,
  `AKIA…`, a PEM header, a JWT) are stored with their content replaced by
  `•••` and only their first 4 characters, so the list shows that something
  was there. State the patterns; they are a net, not a guarantee.
- **Where:** the ledger, a new table via the next migration (check
  `crates/laned-core/migrations` for the number), capped by
  `paste_history_keep` (default 200 entries, 0 = off) and
  `paste_history_days` (default 30). "Clear Paste History" in the Edit menu
  and in Settings, which truly deletes (`VACUUM` not required, but the rows
  go). Excluded from strip export.
- **The picker:** ⇧⌘H is taken? check `Commands.swift`; if free use it, else
  ⌃⌘H. Built on the `SearchPalette` / `OmniPicker` machinery, not a new list:
  newest first, substring filter, each row one line with line count and age,
  ↩ pastes into the focused terminal (through tidy = off, confirm sheet = on),
  ⌘C copies it back to the clipboard, ⌫ with a confirm deletes the entry.
- Setting `paste_history = true`; off means nothing is recorded and the table
  is emptied.
- Tests: each exclusion (the concealed types with a private pasteboard), the
  secret patterns, caps and ageing, private lanes, clear, the picker's ranking
  and its paste path; Rust tests for the table.
- ADR (required): what is recorded, what never is, and why not the system
  clipboard.

## Constraints

- The goal behind all of the paste tasks (the owner, 2026-09-20): *"one of my
  goals is to stop needing iTerm at all as my daily driver."* Match what iTerm
  does where it does it well; do not copy its dialogs where a quieter answer
  fits this app.
- `TerminalPaste`'s header comment is law: **no bracketed-paste markers, ever**,
  and a paste never ends in Return. Read it before touching anything.
- Everything that decides what bytes go out is a pure function in
  `TerminalPaste` with the pasteboard injected; tests use a private named
  `NSPasteboard` and never write to `NSPasteboard.general`.
- Identity: square corners, greens for state, grey at rest, Signal Orange only
  for DONE, no instant transitions (`Motion.*`, Reduce Motion lands at once).
  New sheets follow `ConfirmPopup` / `WebAskSheet`, not `NSAlert`.
- Every new command goes in `Commands.swift`, is rebindable through `[keys]`,
  and is listed in the ⌘/ sheet and the Edit menu.
- Works the same in a remote lane (a session on a relay server) unless the
  task says otherwise.
- Do not quit, replace or launch the installed app; build to
  `MAXPANE_APP=build/verify.app` and do not run it. The orchestrator installs.
- README (there is no terminal paste section yet; the first of these tasks to
  land creates "Pasting into a terminal" and the rest extend it), CHANGELOG,
  and an ADR only where a decision was made that someone will want to reopen.
