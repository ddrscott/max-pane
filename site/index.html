// WHAT_IT_DOES

01

Lanes, not windows.

A terminal and a web page are peers. Each is a portrait column on one horizontal strip; wide content scrolls inside the lane, and the lane never widens past its max. Lanes never overlap.

Three sizes, s | m | xl, in every lane's menu; ⌘\ cycles them. ⌘D splits a pane to the right, the way iTerm does. Drag a lane by its header onto any edge of another, or pick a pane up and drop it in a different column.

02

One lane per agent session.

A sidebar lists every running session and says which one is BLOCKED on a prompt. That one is the brightest green, and it pulses. Click it and you are there.

One green family for status, so the eye has one thing to find. BLOCKED breathes between full strength and 60 % every 1.8 s and never goes out; with Reduce Motion on it holds steady. The claude running inside a pane saves its own transcript, because panes never inherit the session markers of whatever launched the app.

at rest working blocked

03

⌘O starts anything.

A command, a URL, a page you have kept, a session that is already running somewhere else. One key, because "something goes to the right of this" is a single decision.

⌘O runs a command line rather than pretending to be a shell. ⌘-click a file path in a terminal to open it in your editor. Every key is in a keymap file, and Esc does something at last.

$ claude
  ↩  opens a new lane to the right of this one
$ https://docs.anthropic.com/
  ↩  a web lane, same strip, same key

04

⌘G is the gallery.

Every lane on one screen, live. ⌘G again goes back. Lanes can be dragged in the gallery too, and the layout is also one click in the toolbar.

On the strip, the focused lane centres itself when fewer than three fit, first and last included, so the carousel never leaves you at the edge.

05

It keeps your things.

History with no limit, in a window with room for it; another browser's history imports interleaved by date. Pages you star sit on a bookmark bar you can reorder. Passwords live in the Keychain and go nowhere else. Every setting is editable in Settings and stored as TOML that keeps your comments where you put them.

It follows the Mac's light and dark appearance live, terminals and web pages included, with a theme override in the same file.

# ~/.config/maxpane/config.toml
# comments are yours, and stay where you put them
theme = "system"
snap_to_lanes = true
lane_default_pt = 656
font_name = "JetBrains Mono"
font_size = 13

// INSTALL

Two things to install, because the terminal sessions are owned by a separate daemon, relay-tty, and Max Pane attaches to it. That is also why a session already running somewhere else shows up in ⌘O.

1

Install relay-tty

$ curl -fsSL https://raw.githubusercontent.com/ddrscott/relay-tty/main/install.sh | bash

Or, if you already have Node 18 or newer, npm i -g relay-tty. Max Pane needs 1.22.0 or newer.

2

Download the DMG

$Download for macOS

Open it, drag Max Pane to Applications, and open the app.

3

Start an agent

Press ⌘O, type claude, press ↩. Press ⌘/ for every other shortcut.
